# План API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | /health | проверка, что сервис жив |
| GET | /animals | список объявлений |
| GET | /animals/{id} | одно объявление |
| POST | /animals | создать объявление |
| PUT | /animals/{id} | изменить объявление |
| DELETE | /animals/{id} | снять объявление |

## Коды ответов
- 200 — успешно;
- 201 — объявление создано;
- 404 — объявление не найдено.
