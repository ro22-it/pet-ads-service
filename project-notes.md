# Заметки по проекту

## Идея
Один сервис вместо разрозненных групп в соцсетях: все объявления о животных в одном месте.

## Пользователи
- владелец животного — размещает объявление;
- будущий хозяин — ищет питомца по виду и цене.

## Сущность Animal
| Поле | Тип | Описание |
|------|-----|----------|
| id | число | идентификатор |
| name | строка | кличка |
| type | строка | cat, dog, bird, other |
| breed | строка | порода |
| age | число | возраст в годах |
| price | число | цена, 0 — даром |
