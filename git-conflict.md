# Конфликт слияния

## Где возник
Файл `README.md`, строка со статусом проекта.

- В ветке `main` строка изменена на:
  `Статус: в разработке (КП Git).`
- В ветке `docs/readme-status` та же строка изменена на:
  `Статус: спроектировано API, следующий шаг — контейнер с API.`

При `git merge docs/readme-status` Git не смог сам выбрать вариант и показал конфликт:

```
<<<<<<< HEAD
Статус: в разработке (КП Git).
=======
Статус: спроектировано API, следующий шаг — контейнер с API.
>>>>>>> docs/readme-status
```

## Как исправлен
1. Открыл `README.md` и удалил маркеры `<<<<<<<`, `=======`, `>>>>>>>`.
2. Объединил оба варианта в одну строку:
   `Статус: в разработке (КП Git), спроектировано API, следующий шаг — контейнер с API.`
3. Проверил `git status`, добавил файл и сделал отдельный коммит
   «Исправить конфликт слияния в README».
